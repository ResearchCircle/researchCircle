# V2 product delivery milestones

Updated 2026-10-30. Supersedes both the historical P0.0–P0.10 sequence and the security-first G0–G5 pilot gates.

| Milestone | Working behavior | Typical target with four full-time contributors |
|---|---|---|
| Connected demo | Real search, curated shortlist, saved proposal and local cited draft in browser | 2–3 weeks |
| Usable alpha | Named accounts, teams/invitations, versioned editor, sources/draft jobs, Markdown export, opportunity/pursuit/outcomes, ordinary membership checks | 4–6 weeks; 6–8 with contingency |
| Collaboration polish | Concurrent editing if needed, richer exports, graph views and deeper data integrations | After alpha; prioritize from user feedback |
| Security hardening | Stronger isolation/encryption/sharing/recovery and review | Separate later project; not a prerequisite for the above |

See the [specification](17-v2-corrected-specification.md) and [team plan](18-four-person-delivery-plan.md) for interfaces, tickets, ownership and evidence. Dates are estimates under explicit availability assumptions, not promises.

Anurag owns Orin/model integration; T1 discovery/data; T2 workflow/backend; T3 UI/E2E. Local development proceeds with deterministic model fixtures. Complete milestone acceptance uses real database/API/browser flows and actual Orin output. Do not claim advanced security guarantees for this early release.
